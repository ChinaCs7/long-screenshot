# long-screenshot

Windows 桌面滚动长截图小工具，交互参考微信 PC 版：

1. 运行后进入框选状态，拖动鼠标框出要截的区域（只框一次，之后拖四角 / 四边手柄调整大小、框内拖动移动位置）
2. 点底部的「长截图」按钮（或双击选区、按回车）
3. 在选区里用鼠标滚轮上下滚动页面，右侧实时预览拼好的长图
4. 底部工具栏：**保存**（弹窗选择保存路径）、**✕ 取消**、**✓ 完成**（复制到剪贴板）

任何网页、聊天记录、文档、文件列表都能截，不依赖目标程序提供任何接口。

## 运行

需要 Windows 10 2004 及以上（旧版本上遮罩和工具栏会被截进图里）、Python 3.9+。

```bash
pip install -r requirements.txt
python long_screenshot.py
```

- `Esc`：随时退出
- 右键：有选区时取消选区（可以重新框），没有选区时退出
- 复制到剪贴板时同时写入 BMP 和 PNG 两种格式，微信、QQ、浏览器、Office 都能直接粘贴

## 原理

**截取**：选区确认后，冻结画面的遮罩撤掉，换成一个在选区位置「挖了洞」的半透明遮罩窗口
（`SetWindowRgn`）。洞里鼠标事件直接落到底下的程序，所以能正常滚动。
程序每 100ms 用 [mss](https://github.com/BoboTiG/python-mss) 抓一次选区。
遮罩、边框、工具栏、预览窗都设置了 `WDA_EXCLUDEFROMCAPTURE`，不会被截进去。

**拼接**（[stitcher.py](stitcher.py)，纯 numpy，与界面无关）：

1. **行签名**：每行横向切 16 段取平均亮度，一帧变成「高度 × 16」的小矩阵，
   比逐像素比对快几十倍，也不怕细微色差。
2. **固定区识别**：第一次检测到滚动时，数出上下两端「两帧完全没变」的行，
   当作吸顶标题栏、底部输入框，只让中间部分参与拼接，所以长图里标题栏只出现一次。
3. **求滚动距离**：枚举所有位移，给每个位移打分：对得上的**有内容**行数减去 2 倍对不上的行数，取最高分。
   - 按行计数：鼠标悬停高亮只影响几行，不会带偏结果。
   - 只数有内容的行：大片空白对哪个位移都「对得上」，不能当证据。
     多个位移分数接近时判为歧义，跳过这一帧，等内容更有特征再对齐。
4. **游标**：记录当前画面在长图中的位置。往下滚超出末尾就加长，往上滚超出开头就在前面补。
   来回滚动不会重复。
5. **最新帧覆盖**：每一帧都把整个画面写回它在长图中的位置，而不是只追加新露出的行。
   很多程序是「先滚动、后补画」，比如图片延迟加载、底部最后一行晚一帧才画。
   只追加的话，补画前的半成品会永久留在长图里。
6. **滚动条补平**：滚动条夹在滚动区域里却不随内容移动，第 5 条会把每一帧的滑块都「盖章」进长图，
   右侧出现一串滑块。识别办法：内容已经对齐，只有某条窄竖条反复对不上，它就是滚动条。
   输出时用它左侧紧挨着的那一列像素把它补平。
   另外，判断某一行对没对上时会忽略差异最大的那一段，这样滑块、小红点之类的窄元素不会干扰对齐。
7. **丢失后找回**：和上一帧对不上（滚得太快、上一帧恰好是空白）时，拿新画面直接去和已拼好的长图对位。

## 测试

测试也可以用 pytest 一起跑（需另外 `pip install pytest`）：`python -m pytest tests`


```bash
python tests/test_stitcher.py        # 拼接算法单元测试（合成页面，逐像素校验）
python tests/test_selection.py       # 框选调整逻辑单元测试
```

端到端自测：`tests/scroll_target.py` 会打开一个带原生滚动条、自动滚动的长列表窗口，
并打印列表区域坐标，配合命令行参数跳过框选、自动保存：

```bash
python tests/scroll_target.py 14     # 输出 REGION x,y,w,h
python long_screenshot.py --region x,y,w,h --save-to out.png --duration 10
```

## 已知限制

- 仅支持 Windows；多显示器且缩放比例不同时，跨屏选区可能有偏差
- 平滑滚动过快（两次抓帧之间滚过超过选区 80% 的高度）会对不上，适当放慢即可
- 选区内有持续播放的动画、视频时，拼接可能受影响
- 大片纯色、完全重复的内容无法判断滚动距离（这种内容本身也没有唯一解）
- 长图最高 30000 像素
